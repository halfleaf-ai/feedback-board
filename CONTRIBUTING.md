# Contributing

1. Pick an open issue, or open one describing the problem first.
2. Keep each pull request to one change, with a test that fails without it.
3. Run `npm test` and `npm run typecheck` before pushing.
4. Update `docs/` when you change an endpoint or a documented behavior.

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/),
for example `fix(digest): include Sunday feedback`.
